FRIENDS GOLF LIVE - IMPORT SIMPLE GITHUB

Contenu du zip :
- index.html
- styles.css
- app.js
- golf-hero-friends-live.png
- README_GITHUB_SIMPLE.txt

Import dans un nouveau depot GitHub :
1. Creer un nouveau repository GitHub.
2. Dezipper ce fichier.
3. Importer tous les fichiers directement a la racine du depot.
4. Commit changes.
5. Aller dans Settings > Pages.
6. Build and deployment : Deploy from a branch.
7. Branch : main.
8. Folder : /root.
9. Save.

Version incluse :
- accueil avec un seul bouton : Creer une nouvelle partie ;
- assistant etape par etape avec une seule demande par ecran ;
- choix langue par drapeau avec traduction des textes principaux ;
- saisie score mobile avec pave numerique ;
- putts optionnels ;
- journal local des modifications de score.

Note : cette version est une maquette statique. Le vrai temps reel multi-telephones demandera ensuite un backend type Supabase.
