Import dans un nouveau depot GitHub :
1. Creer un nouveau repository GitHub.
2. Dezipper ce fichier.
3. Importer tous les fichiers directement a la racine du depot, sans creer de sous-dossier.
4. Commit changes.
5. Aller dans Settings > Pages.
6. Build and deployment : Deploy from a branch.
7. Branch : main.
8. Folder : /root.
9. Save.

GitHub donnera ensuite une URL publique du type :
https://<compte>.github.io/<nom-du-repo>/

A ouvrir sur le telephone pour tester la version mobile.

Note : cette version est une maquette statique. Le vrai temps reel multi-telephones demandera ensuite un backend type Supabase.
